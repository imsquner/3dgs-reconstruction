# 迁移状态

本次建仓是源码整理，不是一次新训练或 GPU 环境复现。

可独立验证：网页模块测试、协议/预算边界测试、PLY 旋转适配测试、源码语法、固定上游获取、网站静态 HTTP 服务。

`工程/课程扩展/` 中旧 shell 脚本为历史本机操作记录，约 25 个文件仍使用 `/root/.local/share/monogs` 或 `/mnt/d/桌面/image/gpt-6/工程`。不要直接作为队友的新机安装入口，也不要原样运行其中 apt、环境安装或批量实验命令。先按本机 Python/CUDA 和仓库位置审阅路径；默认入口只有根 README 中列出的命令。

`TUM跨场景迭代` 的历史 batch/freeze/audit 脚本依赖既有运行及冻结记录。公开场景协议的绝对路径已替换为 `/datasets/<scene>`；旧协议字节 hash 不适用于公开副本，必须在本机重新落地、验证输入并生成清单。`fixtures/` 下冻结文件仅供测试语义校验，不能直接代表新运行协议。

协作副本增加了下载、数据校验、环境安装与运行入口，并修正了 portable_protocol 对 Windows 路径的支持、跨平台语义 hash 和相应测试夹具读取。原项目源码、冻结实验及数据没有修改。

地图、观测缓冲、504张RGB预览图和完整TUM原始包由 `v0.1.0-assets` Release 分发；下载入口见根README。Replica地图是独立研究包，需要先阅读并接受其条款。新机路径由 `prepare_dataset.py` 校验落地，默认两帧基线入口见RUNNING。GPU编译与实际重建的验证状态和网站加载分开报告，不能由静态HTTP或图片代替。
