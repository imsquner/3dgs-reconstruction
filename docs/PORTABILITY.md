# 迁移状态

本次建仓是源码整理，不是一次新训练或 GPU 环境复现。

可独立验证：网页模块测试、协议/预算边界测试、PLY 旋转适配测试、源码语法、固定上游获取、网站静态 HTTP 服务。

`TUM跨场景迭代` 的历史 batch/freeze/audit 脚本依赖既有运行及冻结记录。公开场景协议的绝对路径已替换为 `/datasets/<scene>`；旧协议字节 hash 不适用于公开副本，必须在本机重新落地、验证输入并生成清单。`fixtures/` 下冻结文件仅供测试语义校验，不能直接代表新运行协议。

本次只在协作副本修正了 portable_protocol 对 Windows 路径的支持、跨平台语义 hash 和相应测试夹具读取。原项目源码、冻结实验及数据没有修改。

大地图和观测缓冲未公开，网站完整场景加载依赖维护者另行提供资产。不要把静态 HTTP 测试通过理解为完整重建质量或完整网站体验通过。
